Υλοποιήθηκε η εφαρμογή “Pawrtal” με τις παρακάτω βασικές λειτουργίες:

1. Δημόσια προβολή απολεσθέντων κατοικιδίων (δεν απαιτείται σύνδεση)

- Προβολή λίστας απολεσθέντων κατοικιδίων σε καρτών
- Αναζήτηση με κείμενο (π.χ. όνομα, ράτσα)
- Φίλτρο είδους (Όλα / Σκύλος / Γάτα / Άλλο)

2. Λειτουργίες Ιδιοκτήτη / Χρήστη

- Προβολή των κατοικιδίων του χρήστη (συνδεδεμένα με τον λογαριασμό του)
- Προβολή ειδοποιήσεων/μηνυμάτων (π.χ. αναφορές εύρεσης, ενημερώσεις ραντεβού)
- Βιβλιάριο Υγείας κατοικιδίου
- Δηλώσεις Απώλειας και Δηλώσεις Εύρεσης, καθώς και Ιστορικό Δηλώσεων (προβολή/επεξεργασία)
- Κράτηση ραντεβού με κτηνιάτρους
- Ιστορικό ραντεβού

3. Portal Κτηνιάτρου

- Ενότητες: Λογαριασμός/Προφίλ, Ραντεβού, Καταχωρήσεις

Τεχνολογίες

- React + Vite
- Tailwind CSS
- Local mock API με json-server (db.json)

Οδηγίες Εκτέλεσης (Local)

1. Εκκίνηση frontend:
    - npm run dev
2. Εκκίνηση mock server:
    - npm run server
